# **App Name**: NexusAI

## Core Features:

- User Authentication: User authentication via username and password. New users have 'pending' status until admin approval.
- Admin Panel: Admin interface to view/approve/revoke user accounts.
- Market Data Display: Display real-time market data for cryptocurrencies (pulled from the Binance API).
- AI-Powered Insights: Leverage the MistralAI model through the OpenRouter API to generate human-like insights and technical analysis summaries from price charts.
- Signal Generation: Generate technical analysis for assets, including support and resistance levels, multi-timeframe analysis, liquidity pools.
- Signal Card Download: User interface to capture the technical analysis summary in a png for download.
- Market Analysis Chatbot: AI chatbot that leverages an LLM, using provided financial knowledge, answering user questions with proper formatting via a markdown tool.

## Style Guidelines:

- Primary color: Cyan (#00E6E6) for a futuristic, tech-driven feel.
- Background color: Dark gradient from dark grey (#0A0A0A) to pure black (#000000) to ensure deep contrast.
- Accent color: Blue violet (#8A2BE2) and bright blue (#007BFF) to add modern and energetic highlights.
- Headline font: 'Orbitron' (sans-serif) for headers, providing a technological, computerized feel.
- Body font: 'Courier New' (monospace) for body text to enhance the tech feel.
- Use vector icons from Phosphor or similar for a consistent, minimalist look.
- Subtle animations (pulse effects, loading spinners) to give a lively experience.
